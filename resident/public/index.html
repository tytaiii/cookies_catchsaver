网站常驻

填网址 + 登录 cookie，服务器替你保持登录态；定时探测是否失效，失效的在这里标红。 之后可以让 AI 带着这份 cookie 取文件、代你在站点上操作。
需要访问令牌
在服务器上执行 cat ~/resident/data/token.txt 取得；只保存在本机浏览器。
添加常驻站
支持三种粘贴：Cookie 请求头、插件导出的表格（名称/值/域/路径/过期…）、cookies.txt。 只贴「值」不行，必须有名字。表格里的域要和网址对得上，已过期的会自动跳过。
加密存放在服务器本地。
适合用 Token 认证的站点（如 GitHub）。会和 cookie 一样加密保存。 Host / Content-Length 这类不允许改的会被忽略。
登录后页面上稳定出现的文字。填了它，判断「是否还登录着」最准。
怎么用
1. 拿 cookie：浏览器登录目标站 → F12 → Network → 任意请求 → Request Headers → 复制 Cookie 整行（不含 Cookie: 前缀也行）。
2. 填「登录特征串」：登录后页面上一定会出现的几个字。带 cookie 请求这个页面却找不到它，基本就是掉登录了。
3. 服务器每 30 分钟带 cookie 访问一次：既是探测，也顺带续期会话。改完直接看卡片上的圆点。
4. AI 取文件：
curl -s -H "X-Token: $TOKEN" "http://127.0.0.1:8901/api/sites/<id>/fetch?path=/api/list"
返回 JSON（文本页面给 text，二进制给 bodyBase64）。需要 POST 时用 -X POST -d '{"path":"/upload","method":"POST","body":"..."}'。
